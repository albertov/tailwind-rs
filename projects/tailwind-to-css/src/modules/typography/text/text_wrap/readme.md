# Text Wrap Utilities

Tailwind CSS utilities for controlling text wrapping behavior.

## Supported Utilities

- `text-wrap` - Allows text to wrap normally (`text-wrap: wrap`)
- `text-nowrap` - Prevents text from wrapping (`white-space: nowrap`)
- `text-balance` - Balances text across lines for better readability (`text-wrap: balance`)
- `text-pretty` - Optimizes text wrapping for aesthetics (`text-wrap: pretty`)
